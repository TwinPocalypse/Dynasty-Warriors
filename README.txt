DYNASTY WARRIORS 17 - weekly auto-refreshing site

1. Create a free GitHub account, then a new PUBLIC repository (e.g. dynasty-tool).
2. Upload everything in this folder, including the hidden .github folder and the empty data folder
   (on github.com: "Add file" > "Upload files"; drag the unzipped folder contents in).
3. Repo Settings > Pages > Source: "Deploy from a branch", branch main, folder / (root). Save.
4. Repo Actions tab > "Refresh data" > "Run workflow" once, so data/ is filled right away.
5. Your site is at https://YOURNAME.github.io/dynasty-tool/ . Bookmark it on any device.

After that it updates itself every Tuesday and Wednesday. The page always pulls your Sleeper rosters live.
If you ever see no data, run the workflow by hand from the Actions tab.
